# AI Coaching Website

##Objectif
Un site web éducatif qui agit comme un coach virtuel en fitness et nutrition.  
Il permet aux utilisateurs de créer un profil, poser des questions, construire des programmes d’entraînement et suivre leur progression.

##Fonctionnalités
- Formulaire de profil (âge, poids, taille, objectif).
- Section Q&A avec l’IA pour le fitness/nutrition.
- Bibliothèque d’exercices avec vidéos.
- Création et sauvegarde de programmes personnalisés.
- Journalisation des séances.
- Tableau de bord avec graphiques de progression.

##Technologies
- **HTML / CSS / JavaScript** pour la structure et l’interactivité.
- **LocalStorage** pour stocker les données dans le navigateur.
- **IA** pour répondre aux questions dans le domaine fitness/nutrition.
