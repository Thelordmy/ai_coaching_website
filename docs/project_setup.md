# Structure du projet – AI Coaching Website

##Organisation des fichiers

- **index.html** : Page principale du site.
- **css/** : Dossier contenant les fichiers de style.
  - `style.css` : Feuille de style principale.
- **js/** : Dossier contenant les scripts JavaScript.
  - `app.js` : Logique de base du site.
- **assets/** : Dossier pour les ressources multimédias.
  - `images/` : Images utilisées dans le site.
  - `videos/` : Vidéos d’exercices.

##Navigation prévue
- Accueil
- Coach
- Programmes
- Journal
- Tableau de bord

##Objectif
Cette structure permet de séparer clairement :
- Le contenu (HTML),
- La présentation (CSS),
- La logique (JavaScript),
- Les ressources (images, vidéos).
