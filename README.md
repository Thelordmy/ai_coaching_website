# AI Coaching Website

## Description

Ce projet est un site web de coaching fitness personnel avec intelligence artificielle. Il permet aux utilisateurs de créer des programmes d'entraînement personnalisés, suivre leur progression, et obtenir des conseils nutritionnels.

## Fonctionnalités

- **Création de compte** : Inscription et connexion utilisateur
- **Profil personnalisé** : Configuration des objectifs, niveau, et préférences
- **Génération d'entraînements IA** : Programmes personnalisés basés sur le profil utilisateur
- **Suivi des entraînements** : Historique et gestion des séances
- **Conseils nutritionnels** : Recommandations alimentaires adaptées
- **Suivi de progression** : Visualisation des progrès et statistiques
- **Chat IA** : Assistant virtuel pour répondre aux questions

## Technologies utilisées

- **Frontend** : HTML5, CSS3, JavaScript (Vanilla)
- **Stockage** : LocalStorage pour la persistance des données côté client
- **Design** : Interface moderne avec animations et gradient backgrounds
- **IA** : Intégration pour la génération de programmes personnalisés

## Utilisation

1. Ouvrir `index.html` dans un navigateur web moderne
2. Créer un compte via la page d'inscription
3. Configurer son profil (objectifs, niveau, disponibilité)
4. Générer des programmes d'entraînement personnalisés
5. Suivre ses progrès et consulter l'historique
